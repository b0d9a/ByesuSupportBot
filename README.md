# Byesu Support Bot

Telegram-бот поддержки для работы через forum-топики в модераторской супергруппе.

## Возможности

- один постоянный топик на пользователя;
- отдельные записи обращений в PostgreSQL;
- выбор типа обращения пользователем: `Вопрос`, `Проблема`, `Оплата`, `Другое`;
- копирование текстов, фото, файлов, voice/video и других поддерживаемых Telegram-сообщений без скачивания файлов;
- ответы модераторов прямо из пользовательского топика;
- служебные топики `Общение`, `Объявления`, `Открытые обращения`, `Закрытые обращения`;
- кнопки закрытия, переоткрытия и смены типа обращения.

## Требования Telegram

1. Создайте супергруппу и включите в ней Topics/Forum.
2. Добавьте бота в группу администратором.
3. Выдайте права на создание, редактирование и закрытие топиков, закреп сообщений и отправку сообщений.
4. Узнайте ID супергруппы в формате `-100...` и укажите его в `SUPPORT_GROUP_ID`.

## Локальный запуск

```bash
npm install
docker compose up -d
copy .env.example .env
npm run migrate
npm run dev
```

В `.env` нужно заменить:

- `BOT_TOKEN` на токен от BotFather;
- `SUPPORT_GROUP_ID` на ID модераторской супергруппы;
- `DATABASE_URL`, если PostgreSQL запускается не из `docker-compose.yml`.

После запуска выполните `/setup` в модераторской супергруппе. Бот создаст служебные топики и сохранит их ID в базе.

## Рабочий сценарий

1. Пользователь пишет `/start`.
2. Бот предлагает выбрать тип обращения.
3. Пользователь отправляет первое сообщение.
4. Бот создает или переоткрывает постоянный топик пользователя, создает новое обращение и копирует сообщение в топик.
5. Модератор отвечает обычным сообщением в этом топике.
6. Бот копирует ответ пользователю.
7. Кнопка `Закрыть` закрывает обращение и forum-топик.
8. Если тот же пользователь пишет снова, бот использует тот же топик для нового обращения.

## Скрипты

- `npm run dev` - запуск через `tsx watch`;
- `npm run build` - TypeScript-сборка в `dist`;
- `npm start` - запуск собранной версии;
- `npm run migrate` - применение SQL-миграций;
- `npm test` - unit-тесты;
- `npm run lint` - проверка TypeScript без записи файлов.
