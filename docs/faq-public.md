# FAQ — Byesu Code

Готовая версия для публикации в боте. Вопросы с неподтверждёнными или быстро устаревающими ответами сюда не включены.

---

## Общие вопросы

**Что такое Byesu Code и зачем он нужен?**
Byesu Code — сервис, предоставляющий доступ к языковым моделям (GPT, Claude, Gemini) через единый OpenAI-совместимый эндпоинт `https://code.byesu.com/v1`. Вы получаете API-ключ, пополняете баланс и подключаете его к своим инструментам (Claude Code, Codex, OpenCode, Cline, Cursor и др.) — без прямых подписок на OpenAI или Anthropic.

---

**Чем Byesu Code выгоднее прямой подписки на ChatGPT или Claude?**
Вы платите только за фактически использованные токены. При нерегулярном использовании это значительно дешевле фиксированной месячной подписки.

---

**Как понять, работает ли сервис прямо сейчас?**
Откройте вкладку «Channel Status» на сайте — там отображается текущий статус каждого канала моделей. Актуальные сообщения о сбоях публикуются в официальном чате [@byesuchat](https://t.me/byesuchat).

---

**Где найти сайт?**
Официальный адрес: [byesu.ru](https://byesu.ru) / [code.byesu.com](https://code.byesu.com)

---

**Есть ли документация?**
Да: [byesu.ru/docs](https://byesu.ru/docs) — подробные гайды по подключению для Codex, Claude Code и OpenCode.

## Модели и тарифы

**Где посмотреть список моделей и цены?**
На странице [byesu.ru/prices](https://byesu.ru/prices#g=bl1&m=gpt-5.4&in=1000000&out=100000&req=1&cur=RUB&f=all) — там калькулятор цен, все группы и модели. Цены могут меняться, поэтому смотрите актуальные данные на сайте.

---

**Что такое группы моделей?**
Модели разделены на группы с разным множителем стоимости:
- **GPT Plus** ×0.025 — 29 моделей (самая экономная)
- **GPT Pro** ×0.1 — 7 моделей
- **Gemini** ×0.03 — 5 моделей
- **Claude MAX** ×0.7 — 5 моделей
- **Claude Kiro** ×0.13 — 5 моделей

Актуальный список моделей в каждой группе — на [странице цен](https://byesu.ru/prices).

---

**Что такое Claude Kiro? Чем отличается от Claude MAX?**
Claude Kiro — отдельная группа с множителем ×0.13, значительно дешевле Claude MAX (×0.7). Обе группы включают модели Claude; точный состав каждой группы — на [странице цен](https://byesu.ru/prices).

---

**Какой API-ключ использовать для GPT и для Claude?**
Один и тот же ключ подходит для всех моделей. Группа определяется в настройках ключа на сайте — не в самом ключе.

## Быстрый старт

**Как начать пользоваться сервисом?**
1. Зарегистрируйтесь на [byesu.ru](https://byesu.ru)
2. Пополните баланс
3. Создайте API-ключ в личном кабинете
4. Подключите ключ к нужному инструменту (Codex, Claude Code, OpenCode)

Подробная инструкция: [byesu.ru/docs](https://byesu.ru/docs) → раздел «Быстрый старт».

---

**Как подключить API к Codex?**
Укажите в файле `~/.codex/config.toml`:
```toml
model = "gpt-5.3-codex"
model_provider = "byesu"

[model_providers.byesu]
name = "Byesu Code"
base_url = "https://code.byesu.com/v1"
env_key = "BYESU_API_KEY"
```
API-ключ сохраните в переменную окружения `BYESU_API_KEY`. Подробнее: [byesu.ru/docs](https://byesu.ru/docs) → раздел «Codex».

---

**Как подключить API к Claude Code?**
Задайте переменные окружения (PowerShell):
```
$env:ANTHROPIC_AUTH_TOKEN = "sk-byesu_..."
$env:ANTHROPIC_BASE_URL = "https://code.byesu.com"
$env:ANTHROPIC_MODEL = "claude-sonnet-4-6"
$env:CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY = "1"
claude
```
Или сохраните в `.claude/settings.json`. Полная инструкция: [byesu.ru/docs](https://byesu.ru/docs) → раздел «Claude Code».

---

**Как подключить API к расширению Claude Code в VS Code?**
Используйте те же переменные окружения или файл `.claude/settings.json`, что и для CLI Claude Code. Подробнее: [byesu.ru/docs](https://byesu.ru/docs) → раздел «Claude Code».

---

**Можно ли использовать Codex без входа через GPT-аккаунт?**
Да. Достаточно прописать API-ключ и провайдера напрямую в конфиге.

---

**Как сменить группу моделей (например, с GPT Plus на GPT Pro)?**
Группа выбирается в настройках API-ключа на сайте. В конфиге инструмента смените значение `provider` или `model` в `config.toml`.

## Ошибки и проблемы

**Что означают коды ошибок?**
- **401** — ключ не передан, недействителен или неправильно указан
- **403** — ключ действителен, но модель или группа недоступна
- **404** — неверный base URL (обычно нужен `/v1` для OpenAI-совместимых клиентов)
- **429** — слишком много запросов, уменьшите параллелизм
- **503** — временная перегрузка группы моделей
- **insufficient_balance** — нужно пополнить баланс
- **model_not_found** — проверьте точный ID модели на [странице цен](https://byesu.ru/prices)

---

**Что происходит при нулевом балансе?**
API возвращает ошибку `insufficient_balance`. Это отдельный код, не 503 — по нему можно однозначно определить причину. Пополните баланс на сайте.

---

**Получаю ошибку 503. Что делать?**
503 — временная перегрузка или недоступность группы моделей. Попробуйте по порядку:
1. Сменить группу моделей (например, с GPT Plus на GPT Pro или Claude).
2. Подождать несколько минут и повторить запрос.
3. Проверить статус на странице «Channel Status».

---

**Codex выдаёт "Reconnecting... 2/5 ... 5/5" и зависает. Что делать?**
Причина — таймаут WebSocket-соединения. Явно пропишите прокси в `~/.codex/.env`:
```
HTTP_PROXY="http://127.0.0.1:ПОРТ"
HTTPS_PROXY="http://127.0.0.1:ПОРТ"
ALL_PROXY="http://127.0.0.1:ПОРТ"
NO_PROXY="localhost,127.0.0.1,::1"
```
После 5 неудачных попыток Codex автоматически переключится на HTTPS.

---

**Получаю ошибку "stream disconnected before completion". Что это?**
Обрыв потокового соединения. Чаще всего — неправильные настройки прокси или VPN. Явно пропишите прокси в `.env` вашего инструмента (см. вопрос про Reconnecting).

---

**В Claude Code вечный таймаут. Как исправить?**
Главная причина — неправильные настройки VPN/прокси. Убедитесь, что прокси явно прописан в конфиге инструмента. Также проверьте, что на балансе есть средства.

---

**API работал, потом внезапно перестал. Почему?**
Проверьте по порядку:
1. Статус каналов на странице «Channel Status».
2. Наличие средств на балансе (ошибка `insufficient_balance`).
3. Не обновился ли ваш инструмент — после обновления конфигурация может сброситься.
4. Стабильность VPN/прокси-соединения.

Если проблема не устранена — напишите в @byesu_support_bot.

---

**GPT 5.4 работает намного медленнее GPT 5.5. Это нормально?**
Да. GPT 5.5 работает в быстром режиме; GPT 5.4 тратит больше токенов на анализ контекста.

---

**Как снизить стоимость запросов?**
Используйте группу GPT Plus (×0.025) — самая экономная. Для стабильности переключитесь на GPT Pro. Актуальные цены: [byesu.ru/prices](https://byesu.ru/prices).

## VPN

**Нужен ли VPN для работы с сервисом из России?**
Зависит от провайдера. Часть пользователей работает без VPN. Важно: VPN с некорректно настроенным прокси — основная причина таймаутов. Если используете VPN, обязательно пропишите прокси в конфиге инструмента.

## Оплата

**Какие способы оплаты доступны?**
МИР и СБП (указаны на сайте). Актуальный список способов оплаты уточняйте на [byesu.ru](https://byesu.ru) — он может меняться.

---

**Платёж отправил, но деньги не зачислились. Что делать?**
Напишите в @byesu_support_bot, указав сумму, способ оплаты и подтверждение транзакции. Такие случаи разбираются индивидуально.

---

**Почему оплата через AliPay зачисляет меньше, чем через крипту?**
Разница — комиссия AliPay. Другие способы оплаты зачисляются без комиссии на стороне сервиса.

## Поддержка и бот

**Как написать в поддержку?**
Напишите в [@byesu_support_bot](https://t.me/byesu_support_bot). После первого сообщения откроется обращение (тикет), на которое ответит поддержка.

---

**Как оставить внутреннюю заметку в топике поддержки?**
Для модераторов: сообщения в топике, начинающиеся с `/`, не отправляются пользователю. Можно использовать `/ignore` или `/заметка` для внутренних заметок.

---

**В боте сейчас недоступны подписки. Это постоянно?**
Подписки через бота планируются в будущем, но сейчас основные силы направлены на стабилизацию API. На текущий момент доступ предоставляется через API-ключ с балансом.
